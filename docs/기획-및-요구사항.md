# AI 취업 비서 기획 및 요구사항 초안

구직자와 이직 준비자가 자신의 경험을 채용 요건과 연결하고 보완할 역량을 파악하도록 돕는다. 사용자 인터뷰를 통한 문제 검증이 필요하다.

## 기술 요소
- Agent: LLM이 문서 검색·공고 검색·상세 조회·요건 비교 도구 중 선택하고 실제 실행한다 (ai/agent.py).
- RAG: 요청마다 data/knowledge.json과 저장 공고 후보의 문단 본문을 TF-IDF로 검색해 답변에 전달한다. 의미 임베딩은 아니며 가상 공고는 일반 검색 근거에서 제외한다. 작은 자료집의 검색 품질을 추가 검증해야 한다.
- 멀티모달: 이미지 자체를 모델에 입력한다. 실제 API 키로 검증해야 한다.

| Must 기능 | 확인 방법 | 기대 결과 | 현재 상태 |
|---|---|---|---|
| AI 상담 | 상담 질문 입력 | 조언 또는 추가 질문 | API 미검증 |
| 공고 추천 | 기술을 입력해 추천 요청 | 검색 공고와 출처, 없으면 없음 안내 | API 미검증 |
| 적합도 비교 | 공고와 경험 입력 | 일치점, 확인 필요 사항, 보완 방법 | API 미검증 |
| 이미지 분석 | 가상 공고 이미지 첨부 | 이미지 내용 분석 | API 미검증 |

각 기능을 3회 시도해 2회 이상 기대 결과가 나오는지 기록한다. 검증 전 충족으로 표시하지 않는다.

브라우저 → FastAPI → AI Agent → 공고 검색 및 OpenAI API. 실제 데이터 확보, 기능 검증, 외부 배포, 팀원 제외 대상 사용자 5명 이상 테스트, 익명 피드백 및 개선 기록, 발표 PDF가 필요하다. 개인정보 보관·삭제·접근 권한과 동의 절차를 설계한다.

구체적인 변경 코드 위치, 검증 범위와 한계는 RAG-Agent-보완.md를 참고한다. 기존 검증 기록은 원본 당시의 관찰을 보존한 것으로 현재 버전의 반복 검증 완료를 뜻하지 않는다.
