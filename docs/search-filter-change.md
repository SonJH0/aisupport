# 공고 검색 필터 보완

## 변경 이유와 동작

배포 커밋 7408e14의 검증에서는 강의·검색 목록이 공고 추천과 섞였고, 신입 요청에 경력 하한이 있는 공고도 포함되었다. 이번 변경은 검색 요약을 기준으로 후보를 정리하며, 원문이나 현재 모집 상태를 확인하는 기능은 추가하지 않는다.

- `ai/web_search.py`: 강의·교육·기사·검색 목록·명시적 마감 결과를 제외한다. 신입 요청에 경력 1년 이상 등의 하한이 보이면 제외한다. 제목이 신입이어도 요약에 경력 하한이 있으면 제외한다.
- 요청에서 인식한 기술명·백엔드/프론트엔드 직무·신입 표기를 요약과 대조한다. 모두 명시되면 `요약 기준 조건 일치`, 누락되면 `추가 확인 필요`로 표시한다. 기술명 언급은 해당 기술이 필수 자격인지까지 증명하지 않는다.
- 기술명은 Python/FastAPI/Java/Spring Boot/Kotlin/React/TypeScript/JavaScript/Node.js/Django/SQL을 지원한다. 지원하지 않는 기술, 지역·연봉·복잡한 OR 조건은 자동 판단하지 않는다. 모든 요청 조건이 검증되었다는 뜻이 아니다.
- Java와 JavaScript를 구분한다. 주니어만 적혀 있으면 신입 가능으로 단정하지 않는다. 추적 파라미터를 제거해 같은 URL의 중복을 줄이고 공고 식별 파라미터는 보존한다.
- `ai/agent.py`: 사용자 원문에서의 조건은 로컬 필터에만 전달하고 검색 서비스에는 모델이 선택한 짧은 검색어만 보낸다. 기존 개인정보 검색어 차단은 유지한다.
- 단독 공고 검색(또는 공고+문서 검색)의 최종 답변은 필터 결과 필드로 직접 표시한다. 모델이 미확인 결과를 확정 추천으로 바꾸지 못하게 한다. 동시에 compare_requirements/get_job을 호출한 복합 요청은 기존 모델 답변을 사용하므로 이 직접 표시 보장은 적용되지 않는다.
- 단독 공고 검색의 참고 자료에는 필터를 통과한 웹 후보만 표시한다. 일반 상담은 답변에서 `[문단ID]`로 인용한 자료만 표시한다. 인용 여부가 관련성의 완전한 판정은 아니며 잘못 인용하면 여전히 노출될 수 있다.

## 검증

- Python 3.12 환경, 자동 테스트 70개 통과(기존 46개 + 추가 24개). `search-filter-tests.xml`에 실제 결과를 저장했다. Starlette TestClient의 httpx 사용 중단 예고 경고 1건이 있었으며 테스트 실패는 없었다.
- Python 컴파일 검사 및 `node --check frontend/app.js` 통과.
- 실제 Brave 검색 3회: Python/FastAPI 신입 백엔드 10건 중 3건 제외, Java/Spring Boot 신입 백엔드 10건 중 6건 제외, React/TypeScript 신입 프론트엔드 10건 중 7건 제외. 원문을 열어 모집 상태를 확인한 검증은 아니다.
- 수정 소스에서 실제 AI 연결 3회: search_live_jobs, search_documents, compare_requirements 실행과 응답을 확인했다. 공고 답변은 일치/추가 확인 필요를 구분했다. 문서 상담 참고 자료는 backend-1/2만 표시되었다. 비교는 Python 어휘 일치, Java 미충족, Kotlin 정보 부족의 의미를 보존했지만 매번 동일한 분류 문구를 보장하지는 않는다.
- 원문 요청·응답·검색 제외 사유·시각은 `search-filter-api-check.json`에 저장했다. 실제 사용자 피드백이 아닌 합성 기술 테스트이다.

## 적용 범위와 한계

검증은 이 수정 소스와 실제 외부 API 연결을 대상으로 했다. Render에는 아직 이 수정본이 반영되지 않았다. 파일 적용·커밋·푸시 후 새 배포에서 다시 확인해야 한다. 이전 `deployment-validation.md`는 수정 전 배포본의 기록으로 그대로 보존한다. 필터가 모든 강의·목록·경력 조건을 완벽하게 잡아낸다고 보장하지 않으며, 검색 요약의 누락·오류·갱신 지연과 복잡한 조건 해석에 한계가 있다. 현재 모집 중인 신입 공고만 확정 추천하는 요구사항을 완전히 구현한 것으로 기록하지 않는다.
