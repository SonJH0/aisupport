# 외부 배포 기능 검증 기록

- 대상: https://ai-job-assistant-xewt.onrender.com
- 배포 커밋: 7408e14 (사용자가 제공한 배포 화면 기준)
- 검증일: 2026-10-28 (한국 시간)
- 범위: 기능별 1회는 사용자가 제공한 화면 관찰, 추가 2회씩은 AI 보조자가 배포 API에 직접 요청.
- 모든 테스트는 합성 기술 테스트이며 실제 사용자 5명의 피드백이 아님.
- API 검증은 화면 조작·모바일·이미지 첨부 검증을 대신하지 않음.

## 판정 기준

- 문서 검색: 질문에 맞는 문서 근거와 공식 문서 링크를 반환하고 search_documents 실행 표시가 있을 것.
- 공고 검색 연결: search_live_jobs 실행 표시, 검색 링크, 모집 상태 미확인 안내가 있을 것.
- 공고 추천 품질: 개별 공고의 기술·신입 조건 충족과 실제 모집 여부까지 확인할 것. 이번 검증에서는 원문을 열어 검증하지 않았으므로 이 품질 기준의 충족을 주장하지 않음.
- 적합도 비교: compare_requirements 실행 표시, 항목별 입력 근거 인용, 명시적 미보유와 미기재 구분이 있을 것. 숙련도·합격 가능성 검증은 아님.

## 요약과 한계

문서 검색 3/3, 비교 분류 3/3이 위 기준대로 동작했다. 공고 검색 연결은 3/3 확인했으나 추천 품질은 3건 모두 부분 성공으로 기록한다. HTTP 200이나 도구 이름만으로 답변 전체의 정확성을 보장하지 않는다. 해당 결과만으로 제출 평가 G1~G7 통과를 확정할 수 없다. 특히 명세서가 실제 모집 중인 신입 공고만 요구한다면 추가 보완과 재검증이 필요하다.

남은 개선: 관련 없는 초기 RAG 참고 자료 노출, 강의·검색 목록의 공고 후보 혼입, 신입·기술·모집 상태 필터링. 이미지 첨부와 대화 연속성은 이번 범위 밖이다. 사용자 피드백은 배포 서비스 실제 이용 후 실제 날짜와 익명화 원문을 따로 수집한다.
