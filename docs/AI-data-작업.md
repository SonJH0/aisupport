# AI 및 데이터 작업 기록

담당: 손재형 (AI 및 DATA)

## 흐름
질문 및 선택적 이미지 → AI가 search_jobs(조건 검색) 또는 get_job(ID 조회)을 선택 → 로컬 JSON을 검색해 결과를 AI에 전달 → 출처를 포함한 답변 생성. 직접 입력한 공고도 비교할 수 있다.

## 세 가지 기술의 현재 상태
- Agent: 두 도구를 모델에 제공하고 호출 결과를 다음 모델 요청에 전달한다.
- RAG: 공고 JSON을 매 요청에 키워드 검색해 응답 생성에 전달한다. 소규모 검색이며 동의어·한글 조사에 약하다.
- 멀티모달: PNG, JPEG, WebP 이미지를 모델 입력으로 전달한다.
- 위 동작은 자동화된 모의 테스트와 별개로 실제 API 키 및 이미지로 통합 검증해야 한다. 인정 여부는 평가 기준과 실제 실행 결과에 따른다.

## 확인 방법
VS Code 터미널에서 `python -m unittest discover -s tests -v`를 실행한다. README의 실행 안내에 따라 서비스를 시작하고 가상 정보를 입력해 상담, Python 공고 추천, SAMPLE-2 공고 비교, 가상 공고 이미지 분석을 확인한다. 각 Must 기능을 서로 다른 입력으로 3회 시도하고 결과를 기록한다. 응답 속도·사실 여부와 공고 출처도 확인한다.

## 남은 작업
실제 공고 데이터의 사용 권한 및 최신성 확보, 검색 품질 평가, API 통합 테스트, 오류 처리, 보안과 사용자 동의, 외부 배포, 대상 사용자 5명 이상 테스트 및 개선이 필요하다. 사용자의 경력·이름·연락처나 API 키를 저장소에 올리지 않는다.
