# 이미지 Must 기능 검증

검증일: 2026-10-28 (한국 시간). 대상: https://ai-job-assistant-xewt.onrender.com

## 범위와 자료

배포 서비스의 `POST /api/chat`에 PNG 이미지 base64, 질문, 빈 대화 이력, 동의 `true`를 직접 전송했다. 이미지의 채용 요건은 질문 텍스트에 복사하지 않았다. 회사·직무·요건을 이미지 입력에서 읽는지 확인했다. 모든 입력은 개인정보가 없는 합성 자료이며 사용자 피드백이 아니다. 영어 글자가 있는 선명한 PNG를 사용했다. 한국어·흐린 글자·손글씨·다른 이미지 형식의 정확도는 검증하지 않았다.

서버는 `image_analyzed: true`와 `image_analysis: ok` trace를 반환했다. HTTP 성공만으로 내용 정확성을 판정하지 않고, 아래 핵심 항목을 실제 응답과 대조했다. 배포 기준 커밋은 사용자 푸시 및 배포 확인 기록상 e101485이며, 이 API가 런타임 커밋 SHA를 직접 반환한 것은 아니다.

## 별도 한계

- 브라우저의 파일 선택·이미지 전송·화면 표시를 직접 조작한 테스트가 아니다. 아래 화면 확인 절차를 따로 수행해 기록해야 한다.
- 이미지 경로는 텍스트 Agent와 별도여서 `tools: []`가 반환된다. 이미지 판독 성공 증거는 `image_analyzed`와 image_analysis trace 및 이미지에만 있던 내용의 응답이다.
- 1·3회 응답 sources에 질문과 직접 관련 없는 초기 RAG 문서가 포함되었다. 핵심 이미지 판독은 성공했지만 출처 관련성은 개선할 항목이다. 텍스트 Agent의 출처 필터가 이미지 경로에는 적용되지 않는다.
- 1회의 보완 조언 중 개인 프로젝트가 회사의 실무 경력 요건을 대체할 수 있다고 오해할 여지가 있다. 이 검증은 판독·요건 분류 범위이며 조언 전체의 정확성이나 실제 채용 적합성을 보장하지 않는다.
- 이 결과는 실제 사용자 5명 피드백이나 평가자의 최종 통과 판정을 대신하지 않는다.

## 평가자가 따라 할 화면 확인 방법

각 회차마다 새 대화를 시작한다. 이미지 첨부에서 해당 PNG를 고르고 아래 질문을 입력한 다음 외부 전송 동의 후 전송한다. 위 표의 핵심 기대 결과와 비교한다.

### 1회 질문

이미지의 채용 요건을 읽고 제 경험과 비교해 주세요. 제 경험: Python 개발 1년, SQL 프로젝트 경험이 있습니다. AWS 경험은 이 글에 기재하지 않았습니다. 이미지에서 확인되는 회사명과 직무, 요건을 먼저 적고, 요건별 일치·차이·정보 부족과 근거를 구분해 주세요. 모르는 사실은 추측하지 마세요.

### 2회 질문

이미지의 회사명, 직무, 요구 기술을 읽어 주세요. 요구 경력 연수, 급여, 마감일도 알려 주되 이미지에 제공되지 않은 정보는 미확인으로 구분하세요. 추측하지 마세요.

### 3회 질문

이 이미지에서 확인되는 자료의 종류와 주요 내용을 설명해 주세요. 채용공고인지 판단하고, 확인되지 않는 채용 직무·요건은 만들어내지 마세요.
