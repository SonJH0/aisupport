# 기능 검증 기록

작성일: 2026-10-28  
대상: AI 취업 비서 개발용 시제품

## 확인된 사례

| 기능 | 입력·확인 방법 | 관찰된 결과 | 한계 |
|---|---|---|---|
| 대화 맥락 | Java·Python 경험을 입력한 후 기술을 반복하지 않고 관련 직무 질문 | 다음 답변에서 Java·Python을 반영 | 브라우저 새로고침 시 대화가 지워짐 |
| 이미지 해석 | 채용공고가 아닌 문서 이미지를 첨부하고 공고 요건 질문 | 공고가 확인되지 않는다고 안내 | 원본 이미지의 각 내용이 정확한지는 이 기록에서 독립 확인하지 않음 |
| 공고 검색 | Python·부산·백엔드 조건으로 공고 요청 | 검색 시각과 공고 후보 링크를 표시 | 원문이나 현재 마감 상태를 자동 검증하지 않음 |
| 적합도 비교 | 경험: Python 1년·SQL 프로젝트; 공고: Python 2년 이상·SQL 필수·AWS 우대 | Python 차이, SQL 일치, AWS 정보 부족으로 분류 | 실제 채용 여부 또는 합격을 판단한 것은 아님 |

위 기록은 해당 사례에서 관찰된 결과이며, 3회 시도 기준을 충족했다는 뜻이 아니다. 테스트 참여자는 팀원 여부가 확인되지 않았으므로 실사용자 5명 요건에 포함하지 않는다.

## 추가 검증 계획

각 Must 기능마다 서로 다른 입력으로 세 번 시도하고, 각 시도일·입력·기대 결과·실제 결과·성공 여부를 기록한다. 3회 중 2회 이상 기대 결과가 나와야 한다는 평가 기준에 따라 판정한다. 같은 입력의 반복도 필요한 경우 별도로 기재한다.

| 기능 | 2차 시도 예시 | 3차 시도 예시 | 기대 결과 |
|---|---|---|---|
| 대화 맥락 | 이전 대화에서 희망 지역 입력 후 지역을 생략한 후속 질문 | 경력을 입력한 뒤 대명사로 후속 질문 | 이전 내용을 반영하고 사실을 지어내지 않음 |
| 이미지 해석 | 개인정보를 가린 선명한 가상 공고 이미지 | 글자가 흐리거나 정보가 빠진 가상 이미지 | 읽을 수 있는 부분과 확인이 필요한 부분을 구분 |
| 공고 검색 | 다른 지역과 직무로 검색 | 검색 결과가 드문 조합으로 검색 | 검색 결과와 원문 링크를 표시하거나 결과가 없음을 알림 |
| 적합도 비교 | 충족 조건과 우대 조건을 모두 명시한 가상 사례 | 경력과 자격 일부를 생략한 가상 사례 | 일치·차이·정보 부족을 근거와 함께 구분 |

## 제출 전 확인

- 이미지 입력, Agent의 두 도구 및 RAG가 실제 평가 기준에 맞게 동작하는지 코드 위치와 함께 점검한다.
- 팀원 제외 대상 사용자 5명 이상에게 테스트를 진행하고, 가명·대상 해당 근거·일자·질문·응답을 별도 기록한다.
- 개선한 사항은 커밋이나 전후 화면에 연결하고, 반영하지 않은 의견의 이유도 남긴다.
- 외부 배포, GitHub 이력, 기획서, 요구 명세서, 발표 PDF와 개인정보 동의 절차를 완료한다.
- 이 파일에 테스트 참여자의 이름·연락처·API 키를 넣지 않는다.
