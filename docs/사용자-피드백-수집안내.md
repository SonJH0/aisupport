# 실사용자 피드백 수집 및 개선 기록

2026-10-29 갱신: 팀원 외 취업 준비생 5명의 응답을 제공받았다. 현재 실제 기록은 [사용자 피드백 기록](사용자-피드백-기록.md)에 있다. 이 파일은 후속 수집을 위한 절차·양식이며, 아래 빈 행은 이미 수집한 응답을 대신하지 않는다. 합성 기술 테스트와 실제 사용자 피드백은 구분한다.

## 대상과 진행

팀원을 제외한 타깃 사용자 5명 이상에게 배포 주소 https://ai-job-assistant-xewt.onrender.com 를 제공한다. 개발 직무 취업·이직 준비 여부와 실제 사용 목적을 익명으로 기록한다. 다른 팀 교육생은 서비스 타깃에 해당할 때만 포함한다. T1 등 가명을 쓰고 이름·연락처·개인 이력서 원문은 저장소에 올리지 않는다.

사용자는 개인정보 없는 경험·공고로 상담·검색·비교 중 필요한 기능을 실제로 사용한다. 이용 후 자발적인 의견을 받는다. 평가용 익명 기록 활용에 동의를 받고, 거절하면 제출 증거에 포함하지 않는다. 동의 수집 자체와 실명·연락처 보관을 혼동하지 않는다. 원문 응답은 익명 처리 외에 유리하게 고쳐 쓰지 않고 AI 요약과 분리한다.

## 질문 예시

1. 현재 어떤 직무를 준비하고 있고, 어떤 도움을 얻기 위해 사용했나요? 개인 이름·회사 연락처 등은 적지 않아도 됩니다.
2. 어떤 기능을 어떤 질문으로 사용했나요?
3. 답변·근거·조건 구분 중 도움이 된 점은 무엇인가요?
4. 부정확하거나 이해하기 어렵거나 불편한 점은 무엇인가요?
5. 가장 먼저 개선했으면 하는 점은 무엇인가요?
6. 의견을 이름·연락처 없이 평가 제출 자료에 사용하는 데 동의하나요?
