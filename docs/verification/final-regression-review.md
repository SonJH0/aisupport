## 이번 코드 보완

- `ai/web_search.py`: 경로가 없는 루트 홈페이지는 개별 공고 근거 부족으로 제외한다. 루트 URL의 쿼리만으로 상세 공고라고 추정하지 않는다. `/positions/1731/...` 같은 개별 경로는 유지한다. 모든 사이트의 목록 페이지를 검출하는 범용 보장은 아니다.
- `ai/comparison.py`: 제한된 단순 기술 경험 요건에 대해서만 명시적 경험·부정·미기재를 구분한다. `experience_status`와 `proficiency_status`를 분리한다. 개인 Python 사용 6개월은 경험의 일치 근거이며 숙련도는 별도 미확인이다. 기간·복합 요건, 복합 문장·불명확한 표현은 기존 의미 확인 상태로 남긴다. 실제 숙련도·합격 가능성을 추정하지 않는다.
- `ai/agent.py`: 단순 경험 일치를 미명시 배포·숙련도 조건으로 낮추지 않도록 지시한다. 사용자가 공고·경험을 직접 제공한 비교에서는 무관한 저장 공고를 초기 검색 근거로 넣지 않는다. 일반 학습 상담의 RAG는 유지한다.
- `tools/validate-final-text.py`: `--cases` 선택 실행을 지원한다. 오류 본문 보존 한도를 1MB로 늘리고 잘림 여부를 기록한다. 기존 실패를 자동 재시도로 숨기지 않는다.

이 수정은 사용자 긍정 후기 때문이 아니라 별도 기술 시험에서 발견한 오류에 따른 작업이다. 502의 근본 원인을 고친 것으로 표시하지 않는다.
