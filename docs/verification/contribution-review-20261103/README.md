## 확인 가능한 중립 요약 — 본인 작성 원문을 대체하지 않음

- 손재윤: FastAPI 기본 API·정적 화면 연결, message/image/history 입력 구조, 텍스트/이미지 AI 함수 분기, 초기 오류 응답 및 .env 로딩이 대표 커밋에 기록돼 있다.
- 황준식: 초기 화면·모드 전환·입력 검증, 이미지 인코딩, /api/chat 호출, 답변·텍스트 URL 표시와 최근 대화 처리가 대표 커밋에 기록돼 있다.
- 손재형: AI·문서 본문 검색·도구 실행·검색 필터·비교·이미지 연결과 후속 진단·검증 자료 정리가 여러 커밋에 기록돼 있다. 후속 기술 보완을 실제 사용자 의견에 따른 수정으로 바꾸지 않는다.

이 요약은 AI의 코드 검토이며 팀원이 직접 쓴 새로운 진술로 표시하지 않는다. 아래 후속 수정 전의 본인 원문은 Git 이력에, 기존 이미지는 [기여 기록](../../팀원별-기여.md)에 보존한다.

## 다음 실제 확인

1. 각 팀원은 위 코드 범위와 본인 요약을 직접 확인한다. 특히 손재윤은 동의 처리·키/모델 설정에 대한 별도 근거가 있는지 확인한다.
2. 별도 근거가 없으면 본인이 해당 설명을 실제 수행 범위로 정정한다. 수정은 본인 계정 커밋 또는 실제 본인 확인 문서로 남긴다. 다른 사람이 대신 본인 작성인 것처럼 기록하지 않는다.
3. 황준식은 초기 URL 표시와 후속 출처 UI·현재 파일 경로를 구분한다. 대표 커밋 연결이 열리는지도 확인한다.
4. 이 대조표 작성만으로 위 본인 확인을 완료했다고 체크하지 않는다. 4단계의 코드 대조는 완료, 본인 정정/추가 근거 확인은 대기다. 운영·보안 5단계와 병행 준비 가능하다.
