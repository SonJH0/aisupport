## 알려진 개선점

- 이미지 답변에 무관한 초기 RAG 출처가 노출될 수 있다.
- Markdown 표·강조·제목 문법이 텍스트로 보여 읽기 어렵다.
- 일반 상담에 도구명·초기 검색 상태가 표시될 수 있고, 배포 후 한 응답에서 불필요한 건강·병력 질문을 관찰했다. 질문 범위와 내부 처리 표시의 개선이 필요하다.
- 공고 검색은 요약의 직무·일부 기술명·신입 표기만 검사하며 원문 최신 모집 여부를 확인하지 않는다. 모든 사이트의 목록 페이지·복잡한 경력·우대 조건을 잡지 못할 수 있다.
- 보관한 초기 명세의 공고 추천 범위를 기준으로 대조했다. 별도 제출 명세가 있다면 함께 대조한다. 최신 선택 실행 6건을 반영했다. 모든 기능을 새로 3회 실행한 것으로 확대하지 않는다.
