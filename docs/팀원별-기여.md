## 손재형 본인 작성란

저는 AI 취업 코치 서비스의 AI·데이터 영역을 담당했습니다. 사용자의 질문에 따라 관련 자료를 검색하고, 채용공고를 찾거나 사용자 경험과 공고 요건을 비교할 수 있도록 AI Agent와 검색 기능을 구현·보완했습니다.

RAG에서는 학습 자료를 검색 가능한 문단으로 구성하고, 질문과 관련된 내용을 검색하여 AI 응답의 근거로 전달하도록 했습니다. 답변에는 참고 자료와 출처를 제공해 사용자가 근거를 확인하고 추가 학습으로 이어갈 수 있게 했습니다.

공고 검색 과정에서는 강의나 검색 목록 페이지가 개별 채용공고처럼 표시되는 문제를 확인했습니다. 이를 해결하기 위해 결과 필터를 보완하고, 검색 요약에서 확인되는 조건과 정보가 부족한 조건을 구분하도록 했습니다. 또한 사용자가 경험을 언급하지 않았다는 이유만으로 해당 역량이 없다고 단정하지 않도록 비교 기준을 보완했습니다.

배포된 서비스의 문서 검색·공고 검색·요건 비교·이미지 분석 결과를 확인하고, 입력과 응답 및 검증 범위를 문서로 정리했습니다. 실사용자 5명의 피드백도 익명으로 정리했습니다. 의견이 모두 긍정적이고 별도 수정 요청이 없어 기존 기능을 유지했으며, 피드백 이전의 기술적 수정과 이후의 검토 결과를 구분해 기록했습니다.

이번 작업을 통해 AI 기능은 응답 생성뿐 아니라 근거 제공, 정보 부족의 명시, 실제 실행 결과의 검증까지 함께 설계해야 한다는 점을 배웠습니다.

대표 증빙: 7408e14, 2789a88, e101485의 코드 변경과 docs/verification/, docs/image-validation/의 검증 기록.

## 손재윤 본인 작성란

저는 AI 취업 코치 서비스의 백엔드를 담당했습니다. FastAPI를 기반으로 프론트엔드의 요청을 받아 AI 처리 결과를 반환하는 API를 구축하고, 사용자 입력부터 응답까지의 연결을 구현했습니다.

요청과 응답의 구조를 정의하여 사용자 메시지와 동의 여부 등 필요한 정보를 전달하도록 했습니다. 프론트엔드와 연동할 때는 요청 형식과 응답 형식이 일치하는지 확인하고, 오류가 발생했을 때 원인을 구분할 수 있도록 처리했습니다.

AI 서비스 연동에서는 API 키와 모델 설정을 환경변수로 관리하고, 서비스 실행 환경에서 해당 설정을 읽어 사용하도록 구성했습니다. 민감한 설정값을 소스 코드와 분리하면서 팀원이 실행에 필요한 항목을 확인할 수 있도록 했습니다.

구현 결과는 API 실행과 프론트엔드 연동을 통해 확인했습니다. 이 과정에서 백엔드는 AI 응답을 전달하는 기능뿐 아니라 입력 검증, 오류 처리, 설정 관리까지 담당해야 서비스가 안정적으로 동작한다는 점을 배웠습니다.

대표 증빙: f228f33의 백엔드 코드 변경, 해당 커밋에 포함된 담당 파일과 API 실행 결과.

## 황준식 본인 작성란

저는 AI 취업 코치 서비스의 프론트엔드를 담당했습니다. 사용자가 상담 내용을 입력하고 AI 응답을 확인할 수 있는 화면을 구성하고, 백엔드 API와 연결하여 서비스 이용 흐름을 구현했습니다.

상담·공고 추천·요건 비교 기능을 사용자가 구분할 수 있도록 화면을 구성했습니다. 입력 영역과 답변 영역을 배치하고, 참고 자료 링크를 통해 답변의 근거를 확인할 수 있도록 했습니다.

프론트엔드와 백엔드를 연결하는 과정에서는 사용자 입력이 요청 형식에 맞게 전달되는지, 반환된 답변과 참고 자료가 화면에 표시되는지 확인했습니다. 화면 구현뿐 아니라 실제 요청과 응답이 연결되는 과정을 점검하며 기능을 완성했습니다.

실사용자 피드백에서는 로그인 없이 바로 접근할 수 있는 점과 기능 구분이 직관적이라는 의견을 확인했습니다. 이를 통해 처음 이용하는 사용자가 서비스의 기능을 이해하고 사용할 수 있도록 화면을 구성하는 것이 중요하다는 점을 배웠습니다.

대표 증빙: aec3c4a의 프론트엔드 코드 변경, 해당 커밋에 포함된 화면 파일과 실제 서비스 화면.
