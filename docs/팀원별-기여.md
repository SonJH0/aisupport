## 손재형 본인 작성란

저는 AI 취업 코치 서비스의 AI·데이터 영역을 담당했습니다. 사용자의 질문에 따라 관련 자료를 검색하고, 채용공고를 찾거나 사용자 경험과 공고 요건을 비교할 수 있도록 AI Agent와 검색 기능을 구현·보완했습니다.

RAG에서는 학습 자료를 검색 가능한 문단으로 구성하고, 질문과 관련된 내용을 검색하여 AI 응답의 근거로 전달하도록 했습니다. 답변에는 참고 자료와 출처를 제공해 사용자가 근거를 확인하고 추가 학습으로 이어갈 수 있게 했습니다.

공고 검색 과정에서는 강의나 검색 목록 페이지가 개별 채용공고처럼 표시되는 문제를 확인했습니다. 이를 해결하기 위해 결과 필터를 보완하고, 검색 요약에서 확인되는 조건과 정보가 부족한 조건을 구분하도록 했습니다. 또한 사용자가 경험을 언급하지 않았다는 이유만으로 해당 역량이 없다고 단정하지 않도록 비교 기준을 보완했습니다.

배포된 서비스의 문서 검색·공고 검색·요건 비교·이미지 분석 결과를 확인하고, 입력과 응답 및 검증 범위를 문서로 정리했습니다. 실사용자 5명의 피드백도 익명으로 정리했습니다. 의견이 모두 긍정적이고 별도 수정 요청이 없어 기존 기능을 유지했으며, 피드백 이전의 기술적 수정과 이후의 검토 결과를 구분해 기록했습니다.

이번 작업을 통해 AI 기능은 응답 생성뿐 아니라 근거 제공, 정보 부족의 명시, 실제 실행 결과의 검증까지 함께 설계해야 한다는 점을 배웠습니다.

대표 증빙: 7408e14, 2789a88, e101485의 코드 변경과 docs/verification/, docs/image-validation/의 검증 기록.

## 손재윤 기여 요약

저는 AI 취업 코치 서비스의 초기 백엔드 구성과 AI 처리 함수 연결을 담당했습니다. FastAPI로 `/api/chat` API를 구성하고, 루트 경로에서 프론트엔드 화면을 제공하며 `/static` 경로로 정적 파일을 제공하도록 했습니다.

사용자 메시지, 선택적 이미지, 최근 대화 이력을 받을 수 있도록 요청 모델을 정의했습니다. 메시지 길이와 대화 역할, 이력 개수에 제한을 두고, 이미지가 포함된 요청은 `analyze_image`, 텍스트 요청은 `respond`로 전달하도록 연결했습니다.

처리 중 발생하는 `ValueError`는 HTTP 400으로, 그 밖의 예외는 안내 문구와 함께 HTTP 502로 반환하도록 했습니다. 실행 시에는 프로젝트 루트의 `.env` 파일을 읽도록 구성했습니다.

제 대표 커밋으로 확인되는 담당 범위는 초기 백엔드 진입점, 입력 구조, 텍스트·이미지 처리 연결, 오류 응답과 `.env` 로딩입니다. 이후 추가된 동의 처리와 키·모델 선택 로직은 이 커밋의 구현 범위에 포함하지 않았습니다. 커밋에 함께 포함된 프론트엔드 파일은 기존 파일과 동일하므로 별도의 신규 화면 구현으로 기재하지 않았습니다.

대표 증빙: [f228f33](https://github.com/SonJH0/aisupport/commit/f228f33)의 `backend/main.py` 변경, [커밋·파일 대조](verification/contribution-review-20261103/README.md).

## 황준식 기여 요약

저는 AI 취업 코치 서비스의 초기 프론트엔드를 담당했습니다. 상담·공고 추천·적합도 비교 기능을 선택하고, 질문이나 사용자 경험·공고 내용을 입력할 수 있도록 화면과 기능 전환 흐름을 구성했습니다.

JavaScript에서 입력값을 확인하고 `/api/chat`에 메시지와 최근 대화 이력을 보내도록 연결했습니다. 이미지를 선택한 경우에는 파일을 데이터 URL로 변환해 요청에 포함하고, 파일 크기와 입력 길이를 검사하도록 했습니다.

반환된 답변은 대화 영역에 표시하고, 답변 텍스트에 포함된 URL은 클릭할 수 있는 링크로 변환했습니다. 사용한 도구 목록과 오류 메시지 표시, 요청 중 버튼 비활성화, 최근 대화 이력 유지와 새 대화 초기화도 구현했습니다.

제 대표 커밋에서 확인되는 출처 관련 화면 작업은 답변 텍스트 속 URL 링크 표시입니다. 이후 추가된 별도 출처 목록 UI, AI 고지와 동의 체크박스 구현은 이 대표 커밋의 기여 범위로 기재하지 않았습니다. 당시 루트 경로의 화면 파일과 현재 `frontend/` 경로를 구분해 증빙을 연결했습니다.

대표 증빙: [aec3c4a](https://github.com/SonJH0/aisupport/commit/aec3c4a)의 `app.js`, `index.html`, `style.css` 변경, [커밋·파일 대조](verification/contribution-review-20261103/README.md).
