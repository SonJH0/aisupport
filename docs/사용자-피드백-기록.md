# 실제 사용자 피드백 기록

문서 작성일: 2026-10-29. 서비스: https://ai-job-assistant-xewt.onrender.com

사용자가 제공한 응답 화면과 후속 확인을 근거로 정리했다. 아래 응답은 앞서 AI가 작성한 예상 피드백이나 합성 기술 테스트와 별개다. AI는 제공된 응답을 전사·요약했으며 응답자의 의견을 새로 작성하지 않았다.

참여자의 팀원 제외·취업 준비 상태·이용일·수집일·동의는 프로젝트 담당자의 확인에 따른다. T2~T5의 시각은 제공 화면에서 읽었고 T1의 14:01은 담당자가 보완했다. 응답 시각을 실제 서비스 실행 시각으로 간주하지 않는다. 각자의 희망 직무·경력·별도 동의 문구 원본은 제공되지 않아 임의로 추가하지 않았다.

## 2. 응답 원문 전사

제공된 이미지의 말풍선 본문을 그대로 전사했다. 자동 줄바꿈은 문장·문단 단위로 합쳤고, 맞춤법·어조·내용은 고쳐 쓰지 않았다. 응답자 닉네임·프로필은 전사하지 않았다. 아래는 화면의 텍스트 전사이며 캡처 이미지 원본 자체와 구분한다.

### T1

> 채용공고와 내가 가진 경험을 비교해서 일치하는 강점과 부족한 약점을 명확히 나누어 정리해 준 거 괜찮았음
>
> 어떤 부분부터 우선순위를 두고 준비해야 할지 파악하기 쉬웠음

### T2

> 제가 직접 작성하지 않은 경험에 대해 함부로 없다고 단정 짓지 않는 점이 인상적이었습니다. 이용자 관점에서 신중하게 안내해 준다는 느낌을 받아 신뢰가 갔습니다.

### T3

> 답변 내용에 관련 참고 자료 링크가 함께 첨부되어 있어서 정말 유용했다. 설명만 읽고 끝나는 것이 아니라, 부족한 부분을 공부할 수 있는 관련 자료로 바로 이동할 수 있어서 효율적으로 대처할 수 있었다.

### T4

> 채용공고 내용을 일일이 텍스트로 옮겨 적으려면 번거로운데, 공고 이미지를 그대로 첨부할 수 있는 기능이 있어서 편리했어요.
>
> 입력 시간을 확 줄여줘서 만족스럽습니다.

### T5

> 로그인 과정 없이 바로 사용할 수 있어서 접근성이 좋았어요. 상담, 공고 추천, 비교 기능이 직관적으로 잘 나뉘어 있어서 처음 이용하는 분들도 사용 방법을 금방 이해하고 편하게 쓰실 수 있을 것 같아요.

## 3. 요약과 반영 판단

프로젝트 담당자 확인: 다섯 명의 의견이 모두 긍정적이었고 별도의 수정 요청이 없어, 이번 사용자 피드백 이후 서비스 코드나 기능을 수정하지 않았다. 현재 기능을 유지하기로 했으며, 이번 작업은 피드백 문서 정리이다.

아래 표는 AI 보조 요약·프로젝트 판단이며 원문 의견과 구분한다. 현재 다섯 응답에는 구체적인 추가 개발 요청이 없다. 긍정적 평가를 새로운 기능 요구나 이미 완료한 개선으로 바꾸지 않는다.

| ID | 의견 요약 | 현재 판단·근거 | 이번 추가 코드 변경 |
|---|---|---|---|
| T1 | 비교와 준비 우선순위 정리에 도움 | 요건별 근거·분류·보완 안내를 유지. 구체적인 추가 변경 요청 없음 | 없음 |
| T2 | 미기재 경험을 미보유로 단정하지 않아 신뢰 | 정보 부족과 명시적 미보유를 구분하는 원칙 유지 | 없음 |
| T3 | 참고 링크를 통한 추가 학습이 유용 | 출처 링크 제공을 유지. 무관한 출처 노출은 별도의 기존 기술 개선점으로 남김 | 없음 |
| T4 | 이미지 첨부가 입력 부담을 줄임 | 직접 이미지 입력을 유지. 시간 단축은 응답자의 체감이며 별도 수치 측정은 하지 않음 | 없음 |
| T5 | 로그인 없는 접근·기능 구분이 편리 | 현재 진입·기능 구분 유지. 모든 신규 사용자에게 쉬움을 증명한 것으로 일반화하지 않음 | 없음 |

이는 긍정적 의견에 대한 유지 판단이며, 피드백을 원인으로 한 새로운 기능 개선·커밋·재검증이 완료됐다는 뜻이 아니다. 기존 공고 필터 수정은 이전 기술 테스트에 따른 개선이므로 이번 사용자 피드백을 반영한 작업으로 소급하지 않는다. 후속 변경이 생기면 의견 ID·변경 근거·커밋·전후 화면·실제 재검증 결과를 이 표에 추가한다.

## 4. 원본 및 추가 확인 사항

- 원본 응답 화면 5개는 프로젝트 담당자가 제공한 첨부 이미지에 보존돼 있다. 이 문서 묶음에는 닉네임·프로필이 남은 캡처를 재포함하지 않았다. 공개 GitHub에 응답 원본 이미지를 넣을 때는 남은 계정 표시를 가명 처리하고 본문과 시각은 보존해 docs/feedback에 추가·연결해야 한다.
- 담당자가 응답자에게 실제로 보낸 수집 질문·테스트 안내 문구는 아직 제공되지 않았다. 임의로 설문 질문을 만들어 과거에 보낸 질문처럼 기록하지 않았다. 실제 문구나 안내 화면이 있으면 여기에 추가한다.
- 응답자별 실제 서비스 질문·AI 응답 원문·테스트 버전은 미제공이다. 현재 원문은 사용 후 의견이며, 해당 입력·출력을 대신하지 않는다.
- 취업 준비생이라는 타깃 근거는 확인했으나 개발 직무 등 구체적인 준비 분야는 미확인이다. 원래 타깃을 개발 직무로 한정한 경우 추가 확인해 기록한다.
- 이름·연락처를 기록하지 않고 T1~T5로만 식별한다. 피드백 수집 완료와 G1~G7 전체 최종 통과는 별개다.
