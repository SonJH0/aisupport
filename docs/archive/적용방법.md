# 바탕화면 원본 폴더에 적용하기

1. VS Code 터미널에서 실행 중인 서버를 Ctrl+C로 종료합니다.
2. 원래 `ai-job-assistant` 폴더를 통째로 복사하여 백업합니다. 백업은 본인 PC에만 보관합니다.
3. 수정본 ZIP을 별도 위치에 압축 해제합니다.
4. 수정본 `ai-job-assistant` 안의 파일과 폴더를 원래 폴더에 복사하여 같은 이름의 코드 파일을 덮어씁니다.
5. 원래 폴더의 `.env`, `.git`, `.venv`는 삭제하지 않습니다. 수정본에는 실제 키가 없습니다. `.env.example`을 기존 `.env` 위에 덮어쓰지 마세요.
6. 원래 폴더를 VS Code로 열고 프로젝트 최상위에서 README의 설치 및 서버 명령을 실행합니다.
7. 이제 서버 하나가 화면과 API를 함께 제공합니다. `http://127.0.0.1:8000`을 사용합니다.
8. 확인한 뒤 git status와 git diff를 보고 실제 검토한 내용을 본인 계정으로 커밋합니다. 이 ZIP에는 .git 이력이 없으므로 새 압축 해제 폴더에서 git init으로 기존 저장소를 대체하지 마세요.

API 응답과 자동 검사 기록은 docs/RAG-Agent-보완.md를 참고하세요. API 키나 원본 .env는 GitHub와 캡처에 올리지 마세요.
